## 실행 결과

결과는 `results/demo/`에 생긴다. 같은 출력 폴더로 다시 실행하면 해당 실험 파일을 갱신한다.

| 파일 | 확인할 내용 |
| --- | --- |
| `layout.png` | 평가 경계, 건물, 서비스·외부 기지국, 후보 위치와 최종 선정한 두 곳 |
| `frequency_sinr.png` | 3.5 GHz와 28 GHz에 각각 100 MHz를 줬을 때의 위치별 SINR. 같은 dB 범례를 사용한다. |
| `bandwidth_cdf.png` | 3.5 GHz / 100 MHz와 28 GHz / 800 MHz의 전송률 누적분포. 왼쪽은 전체, 오른쪽은 실내다. |
| `placement_sinr.png`, `placement_cdf.png` | 28 GHz / 800 MHz에서 기지국 두 곳을 추가하기 전후의 SINR 지도와 전송률 분포 |
| `placement_change.png` | 같은 지점·시행의 추가 후 SINR에서 추가 전 SINR을 뺀 뒤, 지점별 중앙값을 표시한다. 양수는 개선, 음수는 악화다. 별 모양은 추가 위치다. |
| `summary.csv` | 주파수·대역폭 3조건 × 배치 2종의 전체·실내·실외 통계. 잡음전력, SINR 중앙값, 전송률 5백분위·중앙값·평균을 담는다. |
| `grid_metrics.csv` | 위치 좌표와 실내 여부, 각 위치에서 시행한 실험의 SINR·전송률 중앙값 |
| `placement_scores.csv` | 모든 후보 쌍의 좌표, 선정용 시행에서 얻은 5백분위와 중앙값, 기준 대비 변화량, 선택 여부 |
| `run_info.txt` | 사용한 데이터 이름, 격자 수, 시행 횟수, 난수 시드, 선정된 두 위치 |

SINR 지도에서는 **한 위치의 여러 시행**을 중앙값으로 요약한다. CDF와 `summary.csv`는 **모든 위치와 시행**을 한데 모아 계산한다. 5백분위는 오름차순으로 정렬한 표본의 `ceil(0.05 × 표본 수)`번째 값이다. CDF의 가로축은 Mbps 단위의 로그 눈금이며, 표의 수치는 전체 표본으로 계산한다.

## 군자역 조사 자료 넣기

1. 사거리·출입구 주변의 **지상** 평가 경계와 원점을 정한다. 축척이 있는 지도에서 동쪽을 +x, 북쪽을 +y로 삼고, 모든 위치를 원점 기준 미터로 환산한다. 건물과 기지국에 같은 좌표계를 사용한다.
2. 전파누리 ‘이동통신 무선국 찾기’에서 같은 통신사의 4G 위치를 확인한다. 이 위치를 가상 5G 기지국에 사용한다. 평가 경계 밖에서도 간섭을 만드는 인근 사이트를 포함한다. 운영사, 조사일, 지도 출처, 위치 오차, 가정한 높이와 안테나 방향을 기록한다.
3. `data/demo/`를 `data/survey/`로 복사하고 아래 세 파일을 조사 내용으로 바꾼다. `src/simulationConfig.m`의 동·북 범위와 격자 간격도 실제 평가 경계에 맞춘다.

| 입력 파일 | 형식 |
| --- | --- |
| `label.txt` | 그림에 표시할 데이터 이름 한 줄. 조사 장소·출처를 식별할 수 있는 짧은 이름을 쓴다. |
| `sites.csv` | `site_id,role,east_m,north_m,azimuth_deg`. 한 행이 한 사이트이며, 방위각은 북쪽 0°에서 시계 방향으로 잰 첫 섹터의 각도다. 세 섹터는 120° 간격이다. |
| `buildings.csv` | `building_id,east_m,north_m`. 같은 건물의 외곽 꼭짓점을 둘레를 따라 순서대로 나열한다. 건물당 단순 다각형 하나를 지원하며 마지막 변은 자동으로 닫힌다. |

역할은 `service`(접속 가능한 기존 기지국), `external`(항상 송신하는 외부 간섭원), `candidate`(추가 검토 위치) 중 하나다. 서비스 사이트가 하나 이상, 서로 다른 추가 후보가 두 곳 이상 있어야 한다. 선정되지 않은 후보는 송신하지 않는다. 실외만 평가할 때는 건물 CSV에 헤더만 둔다. 이 경우 CDF 그림에는 전체 지점의 분포만 표시된다.

## 계산 기준

- **환경과 전파 모델.** 3GPP TR 38.901 V19.4.0의 도시 매크로셀(UMa)을 적용한다. 기본값은 기지국 높이 25 m, 보행자 단말 높이 1.5 m, 섹터당 총송신전력 43 dBm, 단말 잡음지수 7 dB다. 600 m × 600 m 영역에 10 m 간격으로 3,721개의 평가 지점을 만든다. 건물 경계 위의 격자점은 실내로 센다.
- **경로손실.** 표 7.4.2-1의 실외 거리별 가시선(LOS) 확률을 사용한다. 표 7.4.1-1의 LOS 두 구간식과 `max(LOS, NLOS 후보식)`을 적용하고 음영 표준편차는 4/6 dB를 사용한다. 경로손실 식의 주파수는 GHz, 분기 거리 식의 주파수는 Hz다. 수평거리 10 m 미만에서는 10 m 경계의 손실을 사용하고, 5 km를 넘는 링크는 입력 오류로 알린다.
- **실내와 안테나.** 표 7.4.3-2의 저손실 외벽(유리 30%, 콘크리트 70%)에 실내 깊이당 0.5 dB/m와 단말별 4.4 dB 표준편차의 변동을 더한다. 실내 깊이는 단말별 두 독립 균등표본(0~25 m) 중 작은 값이며, 실외 수평 구간은 전체 거리에서 이 깊이를 뺀 값으로 근사한다. 서비스·외부·후보 링크에 같은 규칙을 적용한다. 세 섹터는 같은 사이트의 채널을 공유하고, 섹터 방향별로 수평·수직 65° 패턴, 최대 감쇠 30 dB, 최대 이득 8 dBi, 하향 기울기 10°를 적용한다.
- **접속·간섭·전송률.** 각 시행에서 대규모 채널 수신전력이 가장 큰 서비스 섹터를 선택한다. 활성화된 나머지 모든 섹터의 전력을 mW로 합산한다. 잡음은 `−174 + 10 log₁₀(B_Hz) + NF_dB` dBm이며 100 MHz에서 800 MHz로 넓히면 9.03 dB 증가한다. 선형 `SINR = S/(I+N)`에서 단일 사용자 Shannon 전송률 `B log₂(1+SINR)`을 계산한다.
- **배치 선정과 검증.** 28 GHz / 800 MHz에서 모든 후보 쌍을 8회 시행해 **전체 전송률의 5백분위**가 가장 큰 쌍을 고른다. 동점이면 중앙값, 그다음에는 CSV 순서로 결정한다. 이후 다른 시드로 20회 평가한다. 각 비교 안에서는 기존 배치·추가 배치와 두 주파수가 같은 LOS 난수, 음영, 관통손실 난수를 공유한다. 같은 주파수에서 대역폭만 바뀌면 같은 수신전력을 재사용한다.

이 모델은 지상의 실외 기지국과 주변 건물 안 보행자를 대상으로 한다. 인접 격자의 공간 상관, 소규모 페이딩, 지하 승강장이나 터널 전파, 다중 사용자 자원 배분은 모델 범위 밖이다. 전송률은 각 사용자가 전체 대역폭을 쓸 때의 이론값이다.
