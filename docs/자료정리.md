# 군자역 5G 미니프로젝트 자료 정리

수정 안내서가 제시한 장소는 세종대 캠퍼스이고, 첨부된 보고서와 MATLAB 코드가 분석한 곳은 순천향대 캠퍼스다. 우리 팀의 대상은 **군자역**이다. 군자역에서 풀 질문은 28 GHz의 넓은 대역폭이 어느 위치에서 전송률을 높이는지, 그리고 기존 배치에 기지국 두 곳을 더하면 취약 구간이 어떻게 달라지는지다.

## 안내서가 제시하는 세 가지 실험

| 비교 | 바꾸는 조건 | 결과에서 읽을 것 |
| --- | --- | --- |
| 1. 주파수 효과 | 3.5 GHz와 28 GHz에 **같은 대역폭 100 MHz** 적용 | 같은 dB 색 범위의 위치별 SINR 지도로 어느 구간이 약해지는지 비교한다. |
| 2. 넓은 대역폭의 효과 | 3.5 GHz / 100 MHz와 28 GHz / 800 MHz | 전송률 누적분포(CDF)의 중앙값과 5백분위를 비교한다. 5백분위는 전체 표본 중 약 5%가 그 이하의 전송률을 얻는 경계값이다. |
| 3. 배치 개선 | 기존 기지국을 유지하고 **두 곳 추가** | 기준 지도에서 두 위치를 고른 이유를 설명하고, 추가 전후의 SINR 지도와 전송률 CDF로 개선·악화 구간을 확인한다. |

비교 간에는 섹터당 총송신전력, 안테나, 사용자 격자와 난수 조건을 맞춘다. 각 위치에서 평균 수신전력이 가장 큰 서비스 후보 섹터를 선택하고, 나머지 후보와 평가 경계 밖의 동일 대역 섹터 전력을 mW 단위로 합산한다. 이렇게 구한 간섭과 잡음으로 `SINR = S / (I + N)`을 계산한다. 전송률 `C = B log₂(1 + SINR)`은 SINR의 선형값과 대역폭 B(Hz)를 사용한 위치별 이론값이다.

**보완 예시를 읽는 방법.** 안내서 21~25쪽의 순천향대 예시에서 3.5 GHz / 100 MHz와 28 GHz / 800 MHz의 전체 중앙 전송률은 각각 251 Mbps와 1,444 Mbps였다. 반면 실내 5백분위는 각각 33.25 Mbps와 3.72 Mbps였다. 넓은 대역폭의 이득이 전체 중앙값에 나타나더라도 실내 취약 지점에서는 다른 결과가 나올 수 있다. 군자역에서는 두 지표를 새로 계산한다.

## MATLAB 초안에서 확인한 계산 문제

| 초안의 처리 | 군자역 모델에서 확인할 점 |
| --- | --- |
| 3행에서 잡음전력을 `-174*1000`으로 계산한다. | −174 dBm/Hz는 잡음전력밀도다. 총 잡음전력은 `−174 + 10 log₁₀(B_Hz) + NF_dB`로 구한 뒤 dBm에서 mW로 변환한다. |
| 414행과 454행에서 `fc=4*10^9`를 GHz 단위가 필요한 경로손실 항에 사용한다. | 식이 요구하는 주파수 단위를 확인한다. 이 항에서 4 GHz의 입력값은 4다. |
| 건물 투과손실 식의 괄호가 어긋나고, 실내 사용자에게 오는 외부 간섭은 실외 함수로 계산한다. | 실내까지 도달하는 서비스 링크와 외부 간섭 링크 모두에 해당 건물 투과 모델을 적용한다. |
| 격자 경계가 중복되고, 하위 5% 집계에서 `Edge_user_C`를 반복해서 덮어쓴다. 지도 색도 정렬 순위로 정한다. | 평가 위치를 한 번씩만 세고, 전송률 표본에서 5백분위를 직접 계산한다. 지도 색은 실제 SINR(dB)에 대응시킨다. |

초안은 모든 위치의 전송률을 합산해 기지국 수로 나누기도 한다. 각 위치에 전체 대역폭을 할당해 구한 이론값이므로, 셀 처리량을 추정하려면 동시 사용자 사이의 자원 배분까지 모델링해야 한다.

## 발표와 평가

발표 10분, 질의응답 5분으로 평가하며 별도 보고서 제출은 요구하지 않는다. 안내서는 LLM 사용을 허용하고, 발표자가 코드·수식·단위와 결과의 원인을 직접 설명하도록 한다.

| 항목 | 배점 | 세부 기준 |
| --- | ---: | --- |
| 구현 정확성과 이해도 | 35점 | 모델·계산 20점, 구현 이해와 질의응답 15점 |
| 비교 실험과 결과 분석 | 35점 | 동일 대역폭 주파수 비교 10점, 전송률 비교 10점, 기지국 추가 위치와 전후 분석 15점 |
| 발표자료 구성과 전달력 | 30점 | 자료 구성·완성도 15점, 전달·시간 배분 15점 |

## 군자역에서의 첫 작업

**1차 범위로 군자역 사거리와 출입구 주변 지상 도로·인접 건물을 제안한다.** 이 범위에서는 안내서의 실외 기지국과 건물 실내 사용자 간 전파 모델을 적용할 수 있다. 지하 대합실·승강장까지 평가하려면 층별 구조와 실내 안테나 위치 자료를 확보하고 지하 구간에 맞는 모델을 정해야 한다.

첫 산출물은 기준 배치도다. 지도에 평가 경계, 좌표 원점과 축척, 건물 윤곽을 표시한다. 이어 전파누리의 ‘이동통신 무선국 찾기’에서 동일 통신사의 4G 위치를 조사해 서비스 후보와 경계 밖 간섭원을 구분한다. 지도에서 확인한 위치와 가상 5G 실험의 송신전력·안테나 가정은 따로 기록한다. 추가할 두 위치는 기준 배치의 SINR 지도를 확인한 뒤 선정한다.
